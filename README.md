## 内存买多大：按程序分档，不按预算分档

先看程序，再看预算。WordPress 裸装大约吃 200MB 内存，主题、插件、定时任务会继续往上吃，1 核 1GB 装完这些，可用内存就很紧张了。Typecho 核心程序只有几 MB，原生支持 Markdown，1 核 1GB 跑起来很轻快。

| 内存 | 适合跑什么 | 不建议用来跑 |
| --- | --- | --- |
| 512MB | 静态站、纯文字的 Typecho | WordPress，后台操作明显卡 |
| 1GB | Typecho 流畅；WordPress 裸装勉强 | WordPress 装一堆插件、多站点 |
| 2GB | WordPress 加主题和常用插件的正常水平 | WooCommerce、电商 |
| 4GB 起 | WooCommerce、多站点、带会员和表单的站 | 高并发资讯站 |

数据库也顺手定一下。计划长期写、以后可能换服务器，用 MySQL，文章多了备份和迁移都方便；只写几十篇、图省事，SQLite 部署最快，代价是迁移时不如 MySQL 顺手。

带宽和流量是第二道坎。轻量类套餐多数是“峰值带宽 + 月流量包”的模式，纯文字博客一个月几百 GB 流量根本用不完，图片多、视频多的站就要往上加档，不然读者打开一半图就断了。

## 备案：大陆节点绕不过去，条件比时间更值得提前看

服务器在中国大陆、用域名对外提供网站服务，就要先完成 ICP 备案。流程是填资料、服务商初审、短信核验、管局审核，一般几个工作日到几周，以实际审核进度为准。

比时间更容易被忽略的是硬性条件：机器必须是包年包月，购买时长通常不少于 3 个月，备案期间剩余有效期不少于 1 个月；要绑定中国大陆境内的公网 IP，带宽不能是 0。刚买一个月按量的机器去提交，会被打回来。

## 从买到上线，六个最容易翻车的地方

**1. 伪静态没配，文章页全部 404。** 改完永久链接，首页看着完全正常，点进任何一篇文章都打不开。这是新站最典型的“上线就翻车”场景，因为在后台改链接格式只是一半，Web 服务器上的重写规则是另一半。改完一定要实际点开一篇文章验证，不要只看首页。

**2. 开了 HTTPS 却没回后台改站点地址。** 页面会出现混合内容告警，样式或图片加载不出来，看起来像主题坏了。把后台的站点地址改成 https 开头，再检查旧文章里有没有写死的 http 图片链接。

**3. 图片传不上去。** 三处要同时满足：`usr/uploads` 目录可写、PHP 的上传大小限制、Web 服务器的请求体大小限制。只改一处往往还是不生效，很多人卡在这里反复重装程序。

**4. 备份只备了数据库。** 恢复之后文章都在，图片全裂，因为附件都在 `usr/uploads` 里。备份要覆盖数据库和站点文件两部分，并且至少做一次恢复演练，能生成备份不等于能恢复。

**5. 容器化部署时数据库地址填了 localhost。** 容器里的 localhost 指向容器自己，填了必然连不上，这是被问得最多的问题之一。

**6. PHP 少开 `pdo_mysql` 扩展。** 安装向导会报连不上数据库，错误提示不会告诉你是扩展没开，容易让人反复核对密码。建 PHP 环境时把 `pdo_mysql`、`mbstring`、`gd` 三个都勾上。

顺手补两条：域名解析要同时加 `@` 和 `www` 两条 A 记录，只加一条会导致带不带 www 只有一个能访问；宝塔面板端口要限制来源 IP，3306 不要对公网开放。

## 上线前逐项点一遍

| 验证项 | 怎么验 | 不通过通常是 |
| --- | --- | --- |
| HTTPS | `curl -I https://域名` 返回 200 | 证书没签发或解析没生效 |
| 文章页 | 点开一篇测试文章 | 伪静态没配 |
| 图片上传 | 文章里插一张图看是否显示 | `usr/uploads` 权限不足 |
| 评论 | 测试文章下发一条评论 | 评论设置或插件冲突 |
| 移动端 | 手机打开站点 | 主题不适配 |
| 后台登录 | 访问后台地址并登录 | 入口路径记错 |

文章页那一项最容易漏，也最容易被读者先发现。

## 完全不想管服务器的人，可以不买

纯文字、没有评论、不在乎绑定某家生态，Cloudflare Pages + D1 + R2 能搭一套不用服务器的博客，R2 每月有 10GB 免费读取和存储空间。代价是流程并不轻松：要 Fork 仓库、建 D1 数据库并分三段执行 SQL 初始化、建 R2 存储桶、绑定自定义域名、配 CORS、把 D1 和 R2 绑定到 Pages，再重新部署一次。哪一步顺序错了都不报错，只是不生效。

能接受这些配置、只想写 Markdown 的话，这套方案的长期成本接近零；想装插件、换主题、做 SEO 精细控制，还是买台服务器省事。
